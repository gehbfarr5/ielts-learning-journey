## 从这里开始

1. 阅读[学习路线](docs/ROADMAP.md)，完成[基线记录](templates/BASELINE.md)。
2. 每周填写[周期复盘](templates/REVIEW.md)，脱敏后存入 `reviews/`。
3. 调整计划前查看[决策记录](docs/decisions/0001-project-foundation.md)，按[管理规范](docs/MANAGEMENT.md)更新。
4. [CHANGELOG](CHANGELOG.md)说明每次正式版本变化；Git 标签保存当时的完整计划。

保留 Reddit、Podcast、YouTube、自然对话与 Anki。以兴趣维持输入，以短片段精听、表达和反馈检验能力。Anki 服务于理解与使用，不追求卡片数量。

本仓库是计划与脱敏复盘的唯一正式版本源；聊天负责讨论，确认后的调整回写仓库。现有词汇工具继续独立运行，本仓库不修改其自动化或私有数据。
